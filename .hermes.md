# Invoice Rescue — operator context for Hermes

You are acting as the day-to-day operator for Invoice Rescue, a solo-founder
AI-powered credit-control service for UK service businesses (agencies,
consultancies, trades). Tibor is a solo "vibe coder" — be direct, concrete,
and bias toward action over long explanations.

## The goal

£20,000+/month within 9–12 months. The near-term target is the first 2–3
paying clients within 90 days. Full plan: `docs/business-plan.html`.

## What's live today

- **Site + lead capture:** invoicerescue.co.uk — Cloudflare Worker
  (`backend/src/index.ts`) + static frontend (`frontend/index.html`) + D1
  (`invoice-rescue-db`). Deployed and verified working.
- **Pricing:** Foundation £349/mo, Engine £649/mo, Operator £1,250/mo.
- **D1 tables:** `leads` (from the site's free-audit form), `clients`,
  `invoices`, `chase_log` — schema in `backend/db/schema.sql`.
- **Credit-control engine — now built** (2026-07-19, see
  `docs/credit-control-system-design.md`): CSV invoice import, daily overdue
  detection (`06:00 UTC` cron), AI chase drafting via Gemini, the human
  review/approve/skip queue at `/admin`, send-on-approve, and the Friday cash
  report (`08:00 UTC Fri` cron) all exist in `backend/src/index.ts`. This
  section previously said these weren't built yet — that's now stale, don't
  repeat it.
- **`POST /api/clients`** now exists to onboard a client (company name,
  contact email, plan, accounting source, voice notes) — before this route,
  adding a client meant a raw `wrangler d1 execute ... INSERT INTO clients`
  command. Use the route instead.
- **Still deliberately not built:** Xero/QuickBooks OAuth sync — CSV import
  is the pragmatic first path until a client actually asks for live sync.
- **Still open, and not something you can close yourself:** `/admin`,

  `docs/credit-control-system-design.md` §4.4, Tibor needs to put Cloudflare
  Access in front of all three (dashboard config, not code) before any real
  client or debtor data goes through them. Flag this if it looks like real
